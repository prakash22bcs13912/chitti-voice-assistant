# 🎙️ Chitti – Hands-Free AI Voice Assistant

Tap the orb once, then just talk. Chitti listens all the time and answers out loud. No buttons.

## ✨ Features
- Always-listening voice chat with live captions
- Voice translation (English, Telugu, Hindi, Tamil, Kannada, Malayalam)
- Say "talk to me in Telugu" and Chitti replies in that language
- Fixes your grammar automatically
- Weather and time by voice
- Natural neural voices with edge-tts

## 🛠️ Tech Stack
Python | Streamlit | Google Gemini | Web Speech API | edge-tts | gTTS

## ▶️ Run locally
```bash
git clone https://github.com/prakash22bcs13912/chitti-voice-assistant.git
cd chitti-voice-assistant
pip install -r requirements.txt
export GEMINI_API_KEY='your-key'
streamlit run chitti.py
```
Open it in Chrome or Edge, tap the orb once, and allow the microphone.
Get a free Gemini key at https://aistudio.google.com/apikey
